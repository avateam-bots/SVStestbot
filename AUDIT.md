# Текущая версия: только квиз

Предыдущий отчёт относился к версии с гео. Полная версия и прежний отчёт сохранены в Desktop/SVSquizBOT.
Здесь оставлены английское подтверждение кнопкой и квиз. Все параметры /start ведут в один сценарий.
Python 3.12, один контейнер, long polling. Единственная обязательная переменная запуска — BOT_TOKEN.
SQLite и /data не используются; незавершённые игры хранятся в памяти.
