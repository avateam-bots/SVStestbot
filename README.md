# SVSdeeplinkBOT — Quiz

Отдельная версия бота: только подтверждение кнопкой и квиз на английском.
Любая команда /start, в том числе с произвольным параметром, запускает один сценарий:
«Please confirm that you are human» → «I am human» → 5 вопросов по 4 варианта → результат.
Кнопка является простым подтверждением, не настоящей CAPTCHA.

Офферы, ссылки, картинки и разделение по гео удалены из этой версии.
Тексты подтверждения и вопросы меняются в config/content.json и обновляются после пересборки.

## Запуск

Нужны Docker и переменная BOT_TOKEN в окружении запуска. Не сохраняйте токен в репозитории.

```powershell
docker build -t svsquizbot .
docker run --rm --name svsquizbot-local -e BOT_TOKEN svsquizbot
```

Python 3.12, стандартная библиотека, один контейнер и long polling.
Постоянное хранилище не требуется: SQLite и /data не используются.
Незавершённая игра и подтверждение сбрасываются при перезапуске.
Одновременно запускайте только один экземпляр бота с данным токеном.
