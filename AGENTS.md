# Требования к проекту

- Версия Python — 3.12.
- `Dockerfile` находится в корне репозитория. Образ собирается с корнем репозитория в качестве контекста сборки и содержит все зависимости бота.
- Сборка образа не требует `BOT_TOKEN` и других параметров.
- Токен передаётся через переменную окружения `BOT_TOKEN` при запуске контейнера.
- При запуске контейнера бот запускается автоматически, без ручных команд.
- Бот запускается одним контейнером и не требует дополнительных контейнеров.
- Бот получает обновления Telegram только через long polling. Не нужно использовать webhook'и.
- Если нужно постоянное хранение данных (чтобы данные переживали перезапуск контейнера), используется SQLite по пути `/data/bot.sqlite3`, если есть необходимость хранить постоянные данные вне SQLite, то они все равно должны храниться в `/data`
- Подготовка хранилища и обновление схемы базы выполняются автоматически при запуске с сохранением существующих данных.
