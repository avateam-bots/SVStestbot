# Требования к проекту

- Версия Python — 3.12.
- `Dockerfile` находится в корне репозитория. Образ собирается с корнем
  репозитория в качестве контекста сборки и содержит все зависимости бота.
- Сборка образа не требует `BOT_TOKEN`, других параметров запуска
  и локального файла `.env`.
- При запуске контейнера бот запускается автоматически, без ручных команд.
- Бот запускается одним контейнером и не требует дополнительных контейнеров
  или отдельно развёрнутых баз данных и очередей. Использование внешних API допустимо.
- Бот получает обновления Telegram только через long polling. Не нужно использовать webhook'и.
- Токен передаётся через переменную окружения `BOT_TOKEN` при запуске
  контейнера.
- Все параметры конфигурации передаются через переменные окружения.
  Обязательные переменные перечислены в `.env.example` с примерами без секретов.
  Файл `.env` внутри контейнера не требуется.
- Если нужно постоянное хранение данных, используется SQLite по пути
  `/data/bot.sqlite3`. Все остальные постоянные файлы также хранятся в `/data`.
- Подготовка хранилища и обновление схемы базы выполняются автоматически
  при запуске с сохранением существующих данных.
